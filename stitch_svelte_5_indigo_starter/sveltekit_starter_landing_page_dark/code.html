Configura tu entorno en segundos

1

Clona el repositorio

Usa git para descargar el starter kit en tu máquina local de forma inmediata.

2

Instala dependencias

Ejecuta pnpm install para configurar el ecosistema de herramientas optimizado.

3

Configura variables

Añade tus claves de API y configuraciones de entorno en el archivo .env.example.

4

Lanza el dev server

Empieza a codificar con npm run dev y disfruta de la velocidad de Vite.
